# Data visualization

Always label criteria, explain scores, show confidence, separate rating from suitability, and express improvement priority without blame. City comparisons require equivalent criteria and disclosed context. Confidence must reflect evidence quality, recency and consistency.

Demo values are illustrative; this system does not calculate validated DarX scores. The 0–100 display range is a provisional implementation convention. Do not imply statistical calibration.
